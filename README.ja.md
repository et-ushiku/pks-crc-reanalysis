# pks 島（コリバクチン）の保有と大腸がん — 公開便メタゲノム 397 検体の再解析

（英語版: [README.md](README.md)。内容は同じです）

**4 つの公開コホートで、pks 島の保有と大腸がんに有意な関連はありませんでした。**
向きは 4 つのうち 3 つでがん側に多いほうに揃いますが、信頼区間は 1 を含みます。

| | |
|---|---|
| 検体数 | **397**（4 コホート・4 か国） |
| 事前に決めた基準で判定できた検体 | **167** |
| 事前に決めた主解析 | **Mantel-Haenszel オッズ比 1.91、95% 信頼区間 0.76〜4.75、P = 0.166** |
| 不均一性 | I² = 17% |

これは最大規模の既報、Piccinno ら 2025（*Nat Med*、18 コホート 3,741 検体）と
**向きも有意性も一致**します。原文はこう書いています。

> Although not significant, the carriage of colibactin-producing genes by
> *E. coli* and *Klebsiella* spp. was increased in CRC
> （有意ではないが、*E. coli* と *Klebsiella* のコリバクチン産生遺伝子の保有は
> 大腸がんで増加していた）

3,741 検体で有意にならなかったものが、397 検体で有意になることはありません。
**これは「効果が無い」ことの証明ではなく、「あったとしても小さい」ことの確認です。**

一致しているのは**結論であって、方法ではありません。**あちらの判定は Anpan の
gene model によるもので、検体を落とす基準は**固定の閾値ではなく、データに当てはめた
種ごとの k-means の境界**です。したがって両者は感度で比較できず、比較もしません。
あちらの基準が実際に何であるかと、本文から解決できなかった 3 点は
[METHODS.md](METHODS.md) に書きました。

**これは診断に使えるものではなく、臨床判断に用いてはいけません。**

## この資料が足しているもの

否定的な結果そのものは既報の 2 例目の独立確認なので、新しさは小さいものです。
作業から出てきたものは他に 3 つあり、**文献と照らして生き残った順**に並べます。

### 1. 島の担い手を、仮定ではなく測った

**最初に見ていただきたいのはここです。**

担い手を調べたのは **2 コホートの陽性 23 検体**で、**強さの違う 2 つの方法**を
使っています。CN-CRC の陽性 14 検体は、**6 種の完全ゲノムを 1 つの索引に入れて
競わせて** MAPQ 20 で測りました（大腸菌 IHE3034、*K. pneumoniae* HS11286、
*C. freundii* CFNIH1、*C. koseri* BAA-895、*E. cloacae* ATCC13047、
*K. aerogenes* KCTC2190）。ゲノム同士を競わせるので、どちらとも決まらない
読み取りは落ちます。読み値は「島の深さ ÷ その種のゲノムの深さ」で、同じ読み取り
集合から出します。DE-CRC の陽性 9 検体は**目印遺伝子との密度比だけ**で見ており、
これは**種を除外できても、種を決めることはできません。**
表の全体は [RESULTS.md](RESULTS.md) にあります。

| 所見 | |
|---|---|
| **どの種にも決められない** | **6 種ゲノムで測った 14 件のうち 4 件。**大腸菌と *K. pneumoniae* の両方が十分にいて、比もどちらも合う。ある対照では大腸菌の比 0.76、Kp の比 0.97 で、どちらもゲノムの覆いが 0.7 超。残り 9 件に使った弱いほうの方法では**この判定自体が出せない**ので、対応する数字はありません |
| 大腸菌より *K. pneumoniae* で説明したほうが合う | **23 件中 3 件（13%）** — **うち 2 件は対照群**。病気との関連が予測する向きの逆 |
| アセンブルで確認できた | 1 件（島と *Klebsiella* の染色体がひと続きのコンティグに載る） |
| **量が多いことは、持っていることではない** | *K. pneumoniae* がゲノム深さ 16.7 倍と **109 倍**（覆い 0.88 超）いるのに、島が追いかけているのは大腸菌、という検体が 2 件 |

**便の読み取りから島の担い手を種のレベルで決める作業は、きちんと試せた 14 件の
うち 4 件（29%）で失敗しました。**しかも失敗するのは、腸内細菌科が 2 種とも
豊富なときに限ります。**割り当てられなかった割合を報告している論文を、まだ見つけていません。**

文献が実際にやっているのは、**大腸菌に倒すこと**です。

- Nooij ら 2021 は、大腸菌が検出されないのに *pks* が出る提供者検体について、
  **11 件中 6 件で *Klebsiella*・*Enterobacter*・*Citrobacter* を実際に検出しながら**、
  「健常提供者には病原性分離株がいないはず」という理由で大腸菌を担い手としました。
  *K. pneumoniae* は普通の腸内常在菌で、病原体の選別では除外されません。
- 同論文の補足図 1 では、19 個の *clb* 遺伝子と大腸菌の単コピー目印 3 つの相関が
  **57 組の中央値 +0.02**（24 組が負）。目印どうしは 0.87〜0.99 です。
  **彼らのデータで *pks* の量は大腸菌の量を追いかけていません。**
  （複数いる大腸菌株のうち 1 株だけが持つ場合も同じになるので、別の担い手の証明では
  ありません。**大腸菌説の裏づけが無い**、ということです。）
- Terlouw ら 2024 は、深い便メタゲノム 25 検体で *K. pneumoniae*・*E. aerogenes*・
  *C. koseri* が「どの検体でも検出されなかった（データは示さず）」と報告しています。
  **Klebsiella を検出しないパイプラインでは、島は定義上すべて大腸菌に帰属します。**

3 件とも引用と出典は [PITFALLS.md](PITFALLS.md) にあります。

### 2. 解析全体が 753KB から再現でき、その近道自体も検算してある

4 コホートの fastq は合計およそ 2.5TB ありますが、**1 バイトも要りません。**
判定はすべて遺伝子ごとの深さの度数分布の関数だからです。この置き換えは期待値の
線形性から厳密で、さらに**実際に fastq を間引いて貼り直した結果とも突き合わせて**
あります。中身と走らせ方は次の節にあります。

### 3. この参照配列についての 4 つの測定値（多くは先行報告あり）

[PITFALLS.md](PITFALLS.md) は、便メタゲノムから *pks* を測るときに踏む 4 つの
落とし穴を書いたものです。**以前の版の README は「どれも文献に見つからなかった」と
書いていました。これは誤りで**、いまは出典を挙げて引用しています
（[CORRECTIONS.md](CORRECTIONS.md) の 9・10・11 番）。項目 3 と 4 は実質的に
Nooij ら 2021 が先取りしていました（既に共通の深さまで間引き、相同性で覆いが歪む
目印遺伝子を見つけて除外している）。**項目 1 は覆いで判定する方法、つまりこちらの
方法にとっての落とし穴で、本数で数える方法にはほとんど影響しません** — ここは
2 回続けて逆に書きました。残るのは測定値です。

1. **約 1,290 塩基の重複で、覆いは約 0.95 で頭打ちになります。**AM229678.1 では
   同じ 1,287 塩基が 16,066〜17,352（*clbK* 内）と 21,719〜23,005（*clbJ* 内）に
   あり 99.845% 一致、MAPQ 20 で落ちます。深さ 10 倍以上では**欠けはこの 2 遺伝子
   だけ**（覆い *clbK* 0.8065 / *clbJ* 0.8450 対 他 16 遺伝子 0.9982）。
   反復配列自体は Auvray ら 2021 が「1480 bp」として報告していますが、
   **どの一致率で測っても再現できません。**
2. **参照配列 55,140 塩基のうち 5,685 塩基は *clb* 遺伝子ではない**ので、島を持たない
   検体でも読み取りが載ります。覆いが 0.1 未満で 50 本以上貼り付いた **106 検体**では、
   中央値 **258 本**（最大 10,548 本）、覆いの中央値は 0.0018 です。
3. **目印遺伝子との密度比には約 1.9 倍の系統的なずれ**があり、
   1.115（= 55140/49455）× 1.14（目印断片の端の損失）× 約 1.50（残り）に
   分解できました。除外には使えますが帰属には使えません。
   **4 つのうち、先行報告を見つけられなかったのはこれだけです。**
4. **島の深さが約 10 倍を下回ると覆いは深さで決まります**（陽性 42 件中 29 件が該当）。
   あるコホートでは群間の深さの差が P = 1.5×10⁻¹⁴ で、生データのまま判定すれば
   **純粋に技術的な理由で**がん群に担い手が多く見えます。

## 生データ無しで結果を再現する

4 コホートの fastq は合計およそ 2.5TB ありますが、**要りません。**

この解析の判定はすべて、18 個の *clb* 遺伝子の位置ごとの深さから決まります。
残す割合を *f* に間引いたときの覆いの期待値は

```
E[覆い] = 平均_i [ 1 - (1-f)^d_i ]
```

で、**深さの順番には依存せず、度数分布だけで決まります**。だからこのリポジトリは
読み取りの代わりに深さの度数分布（753KB）を配っています。

```
python3 code/analyse.py          # 標準ライブラリだけ。scipy 不要。1秒かからない
python3 code/verify_rarefy.py    # 計算で間引いた値と、実際に fastq を間引いて
                                 # 貼り直した値を突き合わせる（2 検体・5 回）
python3 code/verify_extra.py     # 以前は検算できなかったものを計算し直す
                                 # （深さの差・比のずれ・回帰・担い手・接合部・
                                 #   型別・島の contig の帰属）
python3 code/verify_repeat.py    # AM229678.1 から重複を測り直す（要ネットワーク）
```

これで `data/depth_hist.tsv` から覆いを作り直し、保存してある値と照合し、全検体を
2,000 万読み取りに間引き、事前に決めた門を通し、コホート別の表とメタ解析まで
出します。**上の数字がそのまま再現されます。**

この式は期待値の線形性から厳密ですが、**導出は検算ではありません。**2 検体では
実際に `seqtk sample` で fastq を間引いて貼り直し、覆いを測り直しました。
`verify_rarefy.py` が両者を並べます。5 回の差は最大 **0.0211**。同じ深さで種を
変えた 3 回の実測のばらつき **0.0182** と同じ大きさで、**判定は 5 回すべて一致**
します。表と、この検算で**決着しないこと**は [METHODS.md](METHODS.md) にあります。

## 限界

- **共変量を入れていません。** Piccinno 2025 は年齢と性別を調整していますが、
  4 コホート分を揃えられていません。コホートは層として扱っただけです。
- **向きが安定しません。** コホートごとの陽性が 6〜8 件なので、解析を変えると
  向きが動きます。CN-CRC ではオッズ比が 0.85（間引く前）から 2.13（間引いた後）に
  変わります。どちらも有意ではないので、正しい言い方は「有意差なし」であって、
  「がんに少ない」でも「がんに多い」でもありません。
- **担い手の解析は 14 検体と 1 件のアセンブルに乗っています。** *K. pneumoniae* と
  した 3 件のうち、ひと続きのコンティグで確認できたのは 1 件だけ。残り 2 件は
  覆いの比だけが根拠で、保有と矛盾しないというだけであり、証明ではありません。
  しかも測定後に fastq を消したので、いまから確認し直せません。「14 件中 4 件が
  決められない」も、**このコホートのこの深さでの値**であって定数ではありません。
  また、測る前に 1 件を量だけ見て *Klebsiella* と読み違えました
  （CORRECTIONS.md の 8 番）。
- **配列を見ているだけで、働いているかは見ていません。** Auvray ら 2021 は、
  pks 陽性の大腸菌 109 株のうち **16 株（15%）**が *clbB* か *clbD* の変異、または
  *clbJK* 融合によって**遺伝毒性を失っていた**と報告しています（多くは島由来の
  代謝物を少量は作っていた）。メタゲノムで「あり」と判定できるのは遺伝子が
  あることだけで、コリバクチンが作られていることではありません。この解析では
  働く島と壊れた島を区別できず、**15% が不活性なら、本当の関連があっても
  薄まって見えます。**
- **実験はしていません。** 菌の分離も PCR もコリバクチンの測定もありません。
- 作業者は 1 人、コードの独立した再実行もありません。

## 同じ著者の関連する仕事

[et-ushiku/crc-microbiome-reproduction](https://github.com/et-ushiku/crc-microbiome-reproduction)
は、同じ種類の公開便メタゲノムを使って別の問いを扱っています。**群集全体**で
大腸がんと対照が分かれるかどうかです。分かれます。9 コホート・824 人で、
1 研究ずつ外して検証した平均 AUC は 0.82 でした。

今回の結果と並べると、はっきり言えることがあります。**群集のレベルの信号は
本物で再現もするが、この 1 つの島の保有はその在り処ではない。**変異の仕組みが
実験で示されている可動性要素であっても、この 2 群を分けているものではない、
ということです。どちらも検診に使えるものではなく、数字を引く前に両方の
リポジトリの限界の節を読んでください。
